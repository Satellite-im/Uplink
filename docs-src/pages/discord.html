Link a server

You need someone who can manage the Discord server for the first step. After that, anyone with the code can link it in their app.

Tap New at the foot of the rail.

New circleNew spaceAdd a Discord server

Tap Add the bot to your server. Discord opens: pick the server and authorise it. Skip this if the bot is already there.

In any channel of the server, type /ghost link. The bot answers with a six-character code only you see. It works once, for 10 minutes.

Link the server

Talk in a Discord voice channel

The server shows as a group in Messages, its voice and stage channels as spaces, with who's in each. Press one to join: Uplink's bot joins that channel for you, and you talk to the people there.

  • People in Discord see the bot speak as Uplink · your name.
  • Messages in the space go to the channel's chat in Discord, and theirs come back.
  • People in Discord are marked as such in the call; their volume and mute work as anyone's.

The bot's commands

In DiscordDoes
/ghost linkGives a one-time code to link the server in Uplink.
/ghost statusSays how many Uplink links the server has.
/ghost unlinkTakes every link away. The server's group in Uplink says so.

The bot sees what any member of a voice channel sees: who is in it, and the sound and chat of the channel it's bridging while someone from Uplink is in it. The link is a token kept on your device only.
