From nothing to a plugin of your own in a few minutes: load the example Bills plugin in Developer mode, try it on a text, switch it on, then change it and load it again. Trying it works on every platform; seeing it sort your texts needs an Android phone.

Turn on Developer mode

Open Settings › About and tap Version twelve times in a row. Taps more than two seconds apart start the count again, and from the eighth a note says how many are left. On a Mac or Windows PC, press Version in its Settings › About the same way.

Developer mode is on, and Settings › Developer is there now (on an Android phone, Settings › API too). The Developer mode switch at the top of Settings › Developer turns it off again; plugins in development stop while it's off, and come back when it's on.

Get the Bills plugin

In Settings › Developer › Plugins in development, tap Load a plugin from a link and give it this address:

https://gogho.st/docs/examples/bills.ghostplugin

That works on every platform. Or copy the file's words from anywhere (it's plain text) and tap Paste a plugin.

What you see

Bills gets a row of its own, switched off until you agree to what it can do: its version, where it came from, and whether it's running.

A plugin with problems or warnings says how many of each on its row. A warning doesn't stop it loading. Open it to read them: what each one means.

Try it on a text

Tap the Bills row to open its page. Under Try it, type this and tap Try it:

Your bill is ready. Amount due: $45.20 by 3 Dec.

No text needs to come and nothing is sent: it runs Bills on those words as if they came from a number not in your contacts. It says Bills tags the text bill with $45.20, puts it in its Bills tab with $45.20 on the row, and offers Copy the amount. That works on every platform, an iPhone's too.

Switch it on

Back in Settings › Developer, switch Bills on. The first time, a sheet says what it can do, made from the file itself, and that nobody has reviewed it. Tap Switch it on.

Not reviewed by anyone: switch this on only if you made it. Switch it on Not now

On an Android phone, Kinds of text sorts bills before any plugin from another developer, into its Payment reminders. To see your Bills tab, open Marketplace › Kinds of text and switch off Payment reminders in its settings. Now a text like the one you tried goes to Bills:

72$45.2072975 · A bill

A conversation's row keeps its own name; Bills only adds the amount and its caption. While a plugin in development is on, the list says so in a quiet line, A plugin in development is on · Settings › Developer, because its rows look like any other plugin's.

Change it, and load it again

Save the file on your computer, change a phrase (add "your invoice is ready" to the first rule's any, say), and load your copy from a link your computer serves. With the phone plugged in by USB:

python3 -m http.server 8080        # in the folder with your bills.ghostplugin
adb reverse tcp:8080 tcp:8080      # the phone's 127.0.0.1:8080 is now your computer's

Then, in Settings › Developer › Plugins in development, load a plugin from this link. With the same id, your copy takes the place of the one from gogho.st, switched on or off as that was:

http://127.0.0.1:8080/bills.ghostplugin

From then on, each time you save the file, tap Reload on its page and try it again. Plain http works only to the device itself like this; anything else needs https. On a Mac or Windows PC there's no adb to it: serve the folder the same way and load http://localhost:8080/bills.ghostplugin, or on a Mac load the file itself, which Reload reads again.

Give your copy an id of its own, and a name: the examples' ids can't be submitted. A reload whose id has changed is refused, so load it as a new plugin, then remove the old one. Next: The plugin file, or everything Developer mode can do.
