Getting started

Install the app

Get Uplink on an Android phone, a Mac, a Windows PC or a Linux computer.

Uplink comes straight from gogho.st, not an app store, and keeps itself up to date once it's installed.

On an Android phone

  1. Download it

    On your phone, open gogho.st/ghost-messaging.apk (or tap Download for Android on gogho.st).

  2. Let your browser install it

    Open the downloaded file from your notifications or Files › Downloads. The first time, Android says your browser can't install apps: tap Settings, switch on Allow from this source, go back, and tap Install.

  3. Say yes to Play Protect

    If Play Protect asks about an app it doesn't know, tap More details, then Install anyway. It asks because the app isn't from the Play Store, not because something is wrong.

  4. Open it

    The welcome opens. Carry on with The first time you open it.

Android 13 and later: restricted settings

Apps installed from outside the Play Store can't be your texting app, or read notifications, until you allow it. When Uplink asks, tap Open Android's page for Uplink, then ⋮ › Allow restricted settings, and try again.

On a Mac

  1. Download the disk image

    Get ghost-messaging-mac.dmg from gogho.st. It runs on Apple silicon and Intel Macs, macOS 12 or later.

  2. Drag it to Applications

    Open the disk image and drag Uplink onto Applications.

  3. Open it

    Open it from Applications. It's signed and checked by Apple, so it opens without a warning. It updates itself from then on.

On Windows

  1. Download the installer

    Get ghost-messaging-setup.exe from gogho.st. For Windows 10 and 11.

  2. Run it

    Run the installer and follow it. Then open Uplink from the Start menu. It updates itself from then on.

On Linux

  1. Download it

    On Ubuntu, Debian, Linux Mint, Pop!_OS and their family, get ghost-messaging-linux.deb. On any other Linux, get ghost-messaging-linux-x64.tar.gz. For 64-bit PCs (x86-64).

  2. Install it

    Open the .deb to install it with your software centre, or run sudo apt install ./ghost-messaging-linux.deb. With the .tar.gz, unpack it anywhere and run ghost-messaging in its folder; it needs GTK 3 and libmpv, which most desktops have.

  3. Open it

    Open Uplink from your apps. It looks for updates itself from then on (see Updates on Linux).

On an iPhone Coming soon

The iPhone app isn't out yet. When it is, it'll have friends, circles, calls and files, but not your texts: Apple doesn't let apps send or read texts outside the EU.

Updates

The app checks for updates itself and tells you when one is ready. After each update, What's new lists what changed; find it again in Settings › About.

On Android, the first update asks you to allow Uplink to install updates; say yes, the same as for your browser above.

Updates on Linux

Uplink for Linux looks for a new version as it opens and every few hours, and downloads it by itself. What happens next depends on how you installed it:

  • The .tar.gz: the new version is unpacked beside the old one. Click Settings › Updates › Restart to update and it swaps in the new one and opens it. If you don't, it does the same the next time you open the app. This needs the folder you unpacked it into to be yours, such as one in your home folder.
  • The .deb: installing a package needs your password, so the app can't do it alone. It downloads and checks the new .deb, then Settings › Updates shows the one command that installs it, with Copy the install command. Paste it into a terminal, then open Uplink again.

Versions up to 0.12.12 didn't update themselves on Linux. Install the new one once by hand, and it updates itself from then on.
